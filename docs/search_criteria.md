# 후보 검색 기준 예시

이 기준은 전남·광주 통합 상황을 예로 든 것입니다. 다른 지자체나 다른 정비 사유에 적용할 때는 표현을 바꿔야 합니다.

## 전남 시군 예시

| 분류 | 찾는 표현 | 검토 이유 |
| --- | --- | --- |
| 광역 명칭 | `전라남도`, `전남`, `전남도` | 통합 또는 명칭 변경 시 정비 가능성 |
| 광역단체장 | `전라남도지사`, `전남도지사`, 문맥상 `도지사` | 권한자 명칭 변경 가능성 |
| 광역 자치법규 인용 | `전라남도 ... 조례`, `도 조례`, `도 규칙` | 인용 법규 승계·폐지·명칭 변경 확인 |
| 주소 | `전라남도 ○○시/군`, `전남 ○○시/군` | 별지·서식 주소 표기 정비 가능성 |
| 기관명 | `전라남도교육청`, `전라남도행정심판위원회` 등 | 기관 존속·명칭 변경 확인 |
| 재원 | `도비`, `전라남도비`, `도비 보조` | 재원 명칭과 보조 체계 확인 |

## 광주 자치구 예시

| 분류 | 찾는 표현 | 검토 이유 |
| --- | --- | --- |
| 광역 명칭 | `광주광역시`, 문맥상 `광주시` | 통합 또는 명칭 변경 시 정비 가능성 |
| 광역단체장 | `광주광역시장`, 문맥상 광역시장을 뜻하는 `시장` | 권한자 명칭 변경 가능성 |
| 광역 자치법규 인용 | `광주광역시 ... 조례`, `시 조례`, `시 규칙` | 인용 법규 승계·폐지·명칭 변경 확인 |
| 주소 | `광주광역시 ○구`, `광주 ○구` | 별지·서식 주소 표기 정비 가능성 |
| 기관명 | `광주광역시교육청`, `광주광역시행정심판위원회` 등 | 기관 존속·명칭 변경 확인 |
| 재원 | `시비`, `광주광역시비`, `시비 보조` | 재원 명칭과 보조 체계 확인 |

## 실무상 중요한 점

검색 기준은 넓게 잡는 것이 좋습니다. 누락을 줄이기 위해서입니다. 대신 최종 엑셀을 검토할 때 다음을 구분해야 합니다.

- 실제 조례 개정이 필요한 표현
- 단순 주소나 기관명이라 일괄 판단이 필요한 표현
- 문맥상 정비대상이 아닌 오탐
- 소관부서 확인이 필요한 표현

즉 검색 기준은 최종 판단 기준이 아니라, 검토 대상을 모으는 그물입니다.
