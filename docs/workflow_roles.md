# 업무 분담 방식

이 프로젝트의 핵심은 AI가 사람을 대체한 것이 아니라, 사람이 판단해야 할 일과 컴퓨터가 잘하는 일을 분리한 데 있습니다.

## 사람이 한 일

사람은 먼저 업무의 목적을 정했습니다. 예를 들어 "통합특별시 출범에 따라 기존 광역단체 명칭, 광역단체장 권한, 광역 자치법규 인용, 주소, 재원 표기를 찾아야 한다"는 식으로 검토 방향을 잡았습니다.

또한 검색 결과를 보고 무엇이 오탐인지 판단했습니다. `도비`라는 단어가 있다고 해서 모두 조례 개정 대상은 아니고, `시장`이라는 단어도 광역시장인지 구청장·시장 일반 표현인지 문맥을 봐야 합니다. 이런 판단은 행정 실무 경험과 도메인지식이 있어야 합니다.

마지막으로 제출 전 검수도 사람이 맡았습니다. 자동화 결과는 "후보 목록"이지 최종 결재문서가 아닙니다.

## Codex Agent가 한 일

Codex Agent는 사람의 판단 기준을 코드와 문서로 바꾸는 역할을 했습니다.

처음에는 단순 문자열 검색처럼 시작했지만, 실제 산출물을 보면서 다음과 같은 보정이 필요했습니다.

- 조문 칸에 ELIS 내부 ID가 들어가는 문제 제거
- 검색어 주변 일부 문장만 잘려 나와 원문 맥락이 부족한 문제 보정
- 별지·서식 HWP 추출 중 생기는 깨진 글자 제거
- 본문 후보와 별지 후보가 따로 나와 보기 어려운 문제를 통합본으로 해결
- 작업용 시트와 전달용 시트를 분리

이런 수정은 사람이 매번 직접 코드를 짜기 어렵고, 순수 스크립트만으로도 스스로 판단하기 어렵습니다. Codex Agent는 결과를 읽고, 문제를 해석하고, 스크립트를 고쳐 다시 실행하는 중간 작업자 역할을 했습니다.

## 자동화 스크립트가 한 일

스크립트는 대량 반복 작업을 맡았습니다.

- 27개 지자체의 ELIS 코드 확인
- 수만 건의 조문과 첨부파일 수집
- 본문과 별지·별표 텍스트 추출
- 정해진 검색 기준으로 후보 표현 검출
- 엑셀 제출서식과 설명자료 생성
- 후보 행 수, 오류 여부, 누락 여부 집계

컴퓨터는 판단을 잘하지는 못하지만, 같은 일을 수천 번 반복하는 데 강합니다. 그래서 "후보를 넓게 잡고, 근거 위치를 빠짐없이 남기는 일"을 맡겼습니다.

## 왜 빨라졌나

전통적인 방식은 사람이 목록을 열고, 조문을 읽고, 별지를 내려받고, 엑셀에 옮기는 방식입니다. 이 방식은 정확할 수 있지만 시간이 많이 걸리고, 반복 중 누락이 생기기 쉽습니다.

이 프로젝트에서는 사람이 처음에 기준을 잡고, 스크립트가 전체를 훑고, Codex Agent가 중간 산출물의 품질 문제를 계속 보정했습니다. 그래서 사람은 모든 문서를 처음부터 끝까지 읽는 대신, 자동화가 모아온 후보와 근거를 검토하는 데 시간을 쓸 수 있었습니다.

## 다른 업무에 적용하는 방법

같은 방식은 자치법규 외에도 적용할 수 있습니다.

1. 사람이 "검토 기준"을 문장으로 정한다.
2. Codex Agent가 그 기준을 데이터 수집·검색 절차로 바꾼다.
3. 스크립트가 전체 자료를 빠짐없이 처리한다.
4. 사람이 결과를 보고 오탐과 누락 기준을 다시 알려준다.
5. Codex Agent가 스크립트와 산출서식을 보정한다.
6. 최종 판단과 대외 제출은 사람이 한다.

즉 AI 활용의 실무 가치는 "사람 없이 자동 결론을 내는 것"보다 "사람이 판단할 수 있는 상태까지 자료를 빠르게 정리하는 것"에 있습니다.
